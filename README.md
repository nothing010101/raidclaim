# RaidLords Claim (deploy ke Vercel)
1. Upload semua file ini (index.html, api/raid.js, vercel.json) ke repo GitHub baru, struktur folder tetap.
2. Vercel > Add New Project > import repo > Deploy (tanpa setting tambahan).
3. Buka URL Vercel di browser dalam aplikasi wallet, lalu: Connect > Login game > Cek voucher > Claim.
Catatan: jumlah claim ditentukan server RaidLords lewat voucher; halaman ini tidak bisa menambah jumlahnya.
